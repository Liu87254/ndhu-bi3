# 苗栗縣科技執法設備分佈與取締件數視覺化分析

本專案針對苗栗縣轄區內之科技執法設備地點與 113 年下半年取締件數進行 ETL 資料清理、地圖定位標記及視覺化分析網頁建置。

## 📊 資料來源與期間說明
* **資料來源**：苗栗縣政府警察局開放資料
* **資料期間**：113 年下半年 (2024 年 7 月至 12 月)[cite: 7]
* **限制說明**：
  * 部分區間測速與路口科技執法設備於統計期間內處於「設備系統維護中」或「測試階段」，故其統計件數紀錄為 `0件`[cite: 7]。
  * 座標數據依官方公告之經緯度標定[cite: 7]。

## 🛠️ ETL 處理與數據加總驗證
1. **自動化處理腳本**：位於 `etl/process_data.py`，不使用手動抄寫[cite: 7]。
2. **文字與數值清理**：
   * 清理原始 CSV 檔案中地點名稱包含之 `\n` 換行符號[cite: 7]。
   * 移除件數欄位之千分號逗號（`,`）與中文文字（`件`），轉換為整數格式[cite: 7]。
3. **數據加總核對 (Data Audit)**[cite: 7]：
   * **總科技執法設置點數量**：20 處[cite: 7]
   * **113年下半年總取締件數**：`4,735` 件（已通過 ETL 程式自動驗證）[cite: 7]

## 🌐 網頁功能與互動分析
* **地圖視覺化**：採用 Leaflet.js 與 OpenStreetMap 呈現動態地圖標記點[cite: 7]。
* **圖表視覺化**：採用 Chart.js 繪製各地點取締件數長條圖[cite: 7]。
* **互動篩選**：支援依「行政區 / 執法種類」切換篩選地圖與圖表數據[cite: 7]。
* **響應式設計 (RWD)**：支援手機與電腦版寬度瀏覽[cite: 7]。
